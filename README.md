# LOCATION LAB · 校园跑虚拟位置模拟实验室

> 一套**与学校无关**的「虚拟位置模拟」工具链：把操场还原成几何模型 → 生成一条贴着跑道中线走的环形 GPS 轨迹 → 导出 `route.local.json` → 再把真机回传的坐标丢回来，算清它到底偏了多少米。

**在线访问**：https://kevin0521-wjw.github.io/shu-location-lab/
**仓库**：https://github.com/kevin0521-wjw/shu-location-lab
**本地打开**：直接双击 `index.html`，无需服务器。

---

## 先说清楚：它不是上海大学专用的

标题里的「上海大学」只是**第一块被实测的场地**留下的名字，不代表适用范围。整个东西里：

| 部分 | 是否与学校相关 |
|---|---|
| 站点本体、几何反算、坐标转换、导出格式 | **完全无关**，任何学校都能用 |
| `data/*.json` 里的坐标点 | 唯一相关的东西 —— 换个学校 = 换一份坐标 |

所以**任何学校都可以用**：只要按下面的方法把自己操场的坐标描出来，它就是你自己学校的 LOCATION LAB。标准 400 m 田径场全世界都是同一套几何（直道 84.39 m、弯道半径 37.11 m、道宽 1.22 m），拟合参数可以整套复用，真正随场地变的只有**中心坐标、长轴方位角、起点位置**这三样。

至于目前下游的校园跑打卡小程序，**只有上海大学、上海中医药大学在用**——所以现成的路线数据也只覆盖这两所学校的场地。别的学校要用，得先确认自己的打卡端是不是同一套机制、认不认 GCJ02 坐标。

## 它是什么

一个 59 KB 的单文件网页（HTML + CSS + Canvas，零依赖、零网络请求），做四件事：

| 模块 | 作用 |
|---|---|
| **路线沙盘**（`#map`） | 按真实几何参数画出田径场（直道 84.39 m、弯道半径 37.11 m、8 道），把环形路线叠上去，可播放/调速/复位，实时显示里程与用时 |
| **导出** | 一键下载与校园跑面板（如 SHUAutoRun）完全同格式的 `route.local.json`（首末点重复闭环），或复制坐标数组 |
| **位置反算**（`#check`） | 粘贴真机回传坐标（`lat lon` / `lon lat` 都认，也能直接贴整段日志），逐点算到路线折线的**最短距离**，判定有没有落在跑道上 |
| **坐标系转换**（`#geo`） | GCJ02 ⇄ WGS84 双向换算，附上海地区约 500 m 偏移的实测对照 |

### 为什么判据是「到折线的最短距离」

标准 400 m 田径场是**跑道形**（两个半圆 + 两条直道），场内任意一点到中心的距离从 37 m 到 79 m 都可能是合法位置。所以「离跑道中心 60 m」这种判据毫无意义，只有**到路线折线本身的最短距离**才能说明问题。LOCATION LAB 用的是后者——本项目在上大嘉定的真机实测中，回传坐标偏离路线中线 **≤ 0.41 m**。

## 通用化：换成你自己学校的操场

四步，全部离线可做：

1. **取底图**：高德卫星瓦片 z=18（约 0.51 m/px）最合适；z=19 是空瓦片，别浪费时间。
2. **描内外突沿**：在瓦片上标出跑道内沿和外沿各一圈点。
3. **拟合几何**：对白线像素做射线检测 + ICP 椭圆拟合，**锁死 b/a = 0.523**（标准跑道比例）。不锁比例会被旁边的篮球场白线拉成 2.15:1 这种荒唐形状，而且 ICP 会从外圈滑向内圈。
4. **采样导出**：沿第 1 道中线等距采样（一般 90–100 点足够），首末点重复成闭环，写成：

```json
{
  "name": "某某大学田径场",
  "coordinateSystem": "gcj02",
  "points": [{ "latitude": 31.3773462, "longitude": 121.2500595 }, "…"]
}
```

拿到坐标后，站点里「路线」下拉能直接载入，也可以直接热导入到运行中的面板（`POST /api/route`），不用重启。

> 现成样例：`data/route.jiading.json`（上大嘉定，98 点 / 97 段 / 403.1 m / 方位 153.5°）与 `data/route.baoshan.json`（上大宝山，11 点 / 381.4 m）。

## 路线数据是怎么来的（以上大嘉定为例）

1. 高德卫星瓦片 z=18 作底图，标出内外突沿；
2. 射线检测提取白色分道线 → ICP 椭圆拟合（锁 b/a）；
3. 按 84.39 m 直道 + 37.11 m 半径重建几何，沿第 1 道中线等距采 97 点，单圈 **403.1 m**（页面里逐段累加得 402.7 m，差 0.4 m 来自椭球近似，可忽略）。

参数：中心 `31.377538, 121.249512`，长轴方位 153.5°，起点 `31.377346, 121.250060`，坐标系 **GCJ02**（高德 / 微信小程序用的火星坐标）。

## 本地部署

三种方式，任选：

**1. 直接打开（最简单）**
双击 `index.html`。页面不加载任何外部资源，`file://` 协议下功能完整。

**2. 起一个本地静态服务器**
```bash
cd shu-location-lab
python serve.py            # 默认 http://127.0.0.1:8080
python serve.py 9000       # 换端口
```
Windows 下也可以直接双击 `serve.bat`，它会自动起服务并开浏览器。
或者不用脚本：
```bash
python -m http.server 8080
```

**3. 丢进任意静态托管**
Nginx / Apache / GitHub Pages / Vercel / Netlify 都能直接用——这是一堆静态文件，没有构建步骤：

```
index.html          # 站点本体（数据已内联，单文件 59 KB）
data/*.json         # 路线原始数据，供下载与二次加工
.nojekyll           # GitHub Pages 用，关掉 Jekyll 处理
serve.py            # 本地起服务（纯标准库）
serve.bat           # Windows 双击启动
```

> 想改成自己学校的名字：`index.html` 是自包含的，改 `<title>` 和页头 `h1` 两处文字即可，其余全是动态渲染的。

## 免责与边界

- 这是**虚拟位置（GPS 轨迹）模拟**的可视化与验算工具：它负责「算出该报什么坐标、并检查报出来的坐标合不合理」，本身不含注入能力。
- 「校园跑」的规则由学校与平台制定。用虚拟位置顶替真实跑步，在多数学校属于违规（代跑 / 刷跑），可能影响体育成绩乃至纪律处分 —— 用不用、怎么用，请自行判断并承担后果。
- 路线数据来自公开卫星影像的人工标注，**不是官方测量成果**，仅供学习研究；真实场地请以现场标识为准。GCJ02 与 WGS84 混用会整体偏 500 m 左右，务必先对齐坐标系。
